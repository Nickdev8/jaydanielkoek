# Model source files

`jaydanielkoek.blend` is the source file for all project models.

Never delete, move, rename, overwrite, or otherwise modify this file unless the user explicitly asks for that exact action. Keep it in this directory.

## Terminology

`cmodel` always means the 3D model of a physical camera. It never means the virtual camera through which the user views the scene; call that the `viewer camera`.
